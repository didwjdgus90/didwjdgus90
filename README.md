## 🔍 Engineering Approach

```text
Problem
  ↓
Reproduce
  ↓
Measure
  ↓
Find the failure path
  ↓
Improve structure / retrieval / contract
  ↓
Test again
  ↓
Document what changed
```

- **실행 성공보다 검증 가능한 동작**을 중요하게 생각합니다.
- RAG에서는 모델부터 바꾸기보다 **검색 실패 원인과 Retrieval 구조**를 먼저 분석합니다.
- AI 기능도 Backend 기능처럼 **입출력 계약 · 예외 경로 · 테스트**를 명확하게 관리합니다.
- 프로젝트에서는 구현 내용과 팀 전체 성과를 분리해 **내 기여 범위를 설명할 수 있게 기록**합니다.
