## 🔍 Engineering Approach

```text
Problem
  ↓
Reproduce
  ↓
Measure
  ↓
Find the failure path
  ↓
Improve structure / retrieval / contract
  ↓
Test again
  ↓
Document what changed
```

- 실행 여부만 확인하지 않고 **실패 케이스와 검증 기준**까지 확인합니다.
- RAG에서는 모델 교체보다 먼저 **검색 실패 원인과 Retrieval 구조**를 분석합니다.
- AI 기능도 Backend 기능처럼 **입출력 계약 · 예외 경로 · 테스트**를 관리합니다.
- 팀 프로젝트에서는 **팀 전체 결과와 개인 기여 범위**를 구분해서 기록합니다.
